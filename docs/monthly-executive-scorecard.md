## Scorecard Purpose

This monthly scorecard gives leaders a clear view of prior authorization reliability, patient access risk, staff burden, and denial prevention performance.

It is designed to answer:

```text
Is the workflow getting more reliable, or are staff still compensating for system weakness?
```

## Tennessee Orange Priority Markers

Use Tennessee Orange `#FF8200` to mark:

- Critical risk cases
- Red patient access risk
- Reconciliation density above threshold
- Payer variance above expected response time
- Clean claim readiness below target
- Escalation quality below 60

---

## Executive Interpretation

### What improved

- Case ownership is more visible.
- Escalations are happening earlier.
- Trust failure events are being logged instead of hidden.
- Reconciliation work is measurable.
- Clean claim readiness is now part of the workflow conversation.

### What still needs attention

- Documentation readiness is below target.
- Payer response variance is still creating operational drag.
- Reconciliation density remains too high.
- Staff burden signals suggest the workflow still requires manual compensation.

---

## Recommended Monthly Action

```text
Focus next month on documentation readiness, payer response variance, and reconciliation density reduction.
```

## Executive Rule

A prior authorization workflow is not improving if case completion rises while reconciliation density and staff burden also rise.
