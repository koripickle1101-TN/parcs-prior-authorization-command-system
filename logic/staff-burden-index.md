# Staff Burden Index

## PARCS 2.0

**Created by Kori Pickle**

## Purpose

The Staff Burden Index measures whether the workflow is being completed through healthy process design or through hidden human compensation.

A workflow can look successful while quietly creating burnout. PARCS tracks the operational burden behind the completed cases.

## Formula

```text
Staff Burden Index = Manual Verification Count + Reconciliation Events + Escalation Events + Duplicate Work Events + After-Hours Updates
```

## Signals to Track

- Manual verification count
- Reconciliation events
- Escalation events
- Duplicate work events
- After-hours updates
- Repeated payer calls
- Unassigned case volume
- Cases touched by more than three staff members

## Interpretation

| Burden Level | Meaning |
|---|---|
| Low | Workflow is stable |
| Moderate | Watch for operational drag |
| High | Staff are compensating for process weakness |
| Critical | Workflow is operating through burnout risk |

## Executive Use

This metric helps leadership avoid the false assumption that completed cases always mean a healthy workflow.

## Control Rule

If cases are getting completed but staff burden is rising, the workflow is not truly improving.
