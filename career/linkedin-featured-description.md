PARCS 2.0 is a healthcare operations portfolio project I designed to analyze prior authorization workflow reliability. It focuses on patient access risk, denial prevention, documentation readiness, trust failure events, reconciliation density, staff burden visibility, and clean claim readiness.

This project demonstrates my ability to think through healthcare workflow breakdowns, design operational controls, build KPI logic, and communicate findings through executive-style reporting.
